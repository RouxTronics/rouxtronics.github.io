# DNS 
## Configure 
```sh
echo "$TARGET support.htb" | sudo tee -a /etc/hosts
```


# SMB

## NULL User 

```sh
nxc smb $TARGET -u '' -p ''
nxc smb $TARGET -u '' -p '' --users
nxc smb $TARGET -u '' -p '' --shares
```

![](<./attachments/02.1-Enumeration.png>)


## View Shares 
Using CLI Tool: [[SMBClient]]
```sh
smbclient -L //support.htb -N
```

![](<./attachments/02.1-Enumeration-2.png>)
> Found non-default share `support-tools`  

## Access `support-tools` share 

```sh
 smbclient //support.htb/support-tools
```

> Can be access with NULL password `press Enter` leave blank

![](<./attachments/02.1-Enumeration-1.png>)

> The share contains tools, `UserInfo.exe.zip` stands out
